# Warehouse Sim

A warehouse decision-rehearsal simulator for the NVIDIA hackathon. Operational agents negotiate dock, yard and crew commitments through an authoritative engine, shown in simple blocky 3D.

The product requirements are in [`docs/idea_intro.md`](docs/idea_intro.md).

```bash
pnpm install
pnpm dev     # http://localhost:3000
pnpm test
```
