# Lessons
- Build every 3D view in React Three Fiber (mockups included), with real downloaded free models for vehicles and equipment; keep primitives only for the S1-scaled facility and as a fallback behind the same entity IDs. Why: the first mockup used vanilla three.js and primitives; the user expected R3F and the online assets.
- In mockups and fixtures, label every placeholder value as illustrative (or synthetic); never give it a real provenance class such as user-supplied, simulated or measured. Why: the first mockup labeled made-up numbers "user-supplied" and "simulated" next to a "0 invented" badge.
- Look at a 3D asset rendered before describing or recommending it; file names lie. Why: Kenney `truck.glb` was described as a box truck and it is a pickup.
- Serve mockups with `python3 docs/mockups/serve.py` (Cache-Control: no-store), not `python3 -m http.server`, and after editing a page check that its modules were re-fetched (transferSize > 0); after switching from http.server, do one hard reload (Cmd+Shift+R) or disable cache in DevTools, since no-store does not evict old entries. Why: http.server sends no Cache-Control, so the browser kept a stale ui.js and a working fix looked broken.
- Never leave the shared browser on a failure-injection test (blocked routes, odd localStorage); reload a clean page afterwards. Why: the user saw "models failed" from a test page left open.
- Build UI as React components in the Next.js app, not as standalone HTML pages; a mockup is only for a question the user asked to explore visually. Why: the dashboard was built as an HTML page and the user wanted the real React frontend.
- After testing at a fixed viewport size in the shared browser, set the viewport back to the browser window's size. Why: a 1600 px test viewport inside a 1920 px window left a grey strip the user took for a layout bug.
- Run `pnpm check` before pushing any commit that includes files written by a tool (bd init, generators), not just code you wrote. Why: bd init committed `.beads/metadata.json` without a final newline and CI failed on Biome.
